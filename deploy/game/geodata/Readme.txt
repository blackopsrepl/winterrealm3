#   Geodata and pathnode files are derived   #
#   from Lineage II client map data and are  #
#   deliberately not part of this            #
#   repository.                              #
#                                            #
#   Place .l2j files in data/geodata/ and    #
#   .pn files in data/pathnode/ next to the  #
#   game server (relative to l2jserver.jar), #
#   then set GeoData = 1 or 2 in             #
#   config/options.properties.               #
#                                            #
#   The repository helper does this for you: #
#     scripts/fetch-geodata.ps1              #
#     scripts/linux/fetch-geodata.sh         #
#                                            #
#   See the main repository README.md for    #
#   download locations and exact steps.      #
